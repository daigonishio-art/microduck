# #1_callout

**MicroDuck 呼びかけ応答プロジェクト**

Version: 0.1.0  
Status: Planning / Pre-hardware development  
Platform: MicroDuck  
Language: Python（予定）  
Reinforcement Learning: Not required

---

## 1. Project Overview

### 目的

MicroDuckが「MicroDuck！」と呼びかけられたときに、人の顔を探索し、発見した相手の方を向いて鳴いて返事をする機能を実装する。

単に音声コマンドに反応するのではなく、呼びかけた相手を探し、見つけたら相手を見つめるという、ペットらしい行動を目指す。

本プロジェクトでは音源方向推定（TDOA等）は使用しない。

### 基本コンセプト

> 呼ばれたら、起き上がり、周囲を探し、相手を見つけて、こちらを見る。

---

## 2. Behavior Specification

### 全体の動作

1. 「MicroDuck！」という呼びかけを検知する。
2. 現在の姿勢を確認する。
3. 座位または伏位であれば起立する。すでに立位なら起立動作をスキップする。
4. カメラを稼働させ、人の顔を検出する。
5. 顔が見つからない場合、右または左にランダムに90度旋回する。
6. 旋回後、再びカメラ画像から顔を探索する。
7. 顔が見つかったら、その方向へ首を向ける。
8. 鳴き声を1回再生する。
9. 相手の顔を見つめ続ける。
10. 一定時間経過後、通常の待機状態に戻る。

### 顔の選択ルール

複数人の顔が検出された場合は、**画面中央に最も近い顔**を選択する。

この段階では個人の識別は行わない。顔の検出（Face Detection）のみを使用する。

### 探索ルール

| 項目 | 仕様 |
|---|---|
| 最初の探索 | 現在のカメラ視界 |
| 顔がない場合 | 右または左へランダムに旋回 |
| 旋回角度 | 90度 |
| 旋回回数 | 1回 |
| 旋回後 | 再度、顔を探索 |
| 旋回後も顔がない場合 | 探索終了 |
| 音源方向推定 | 使用しない |

※90度旋回は胴体の旋回を想定。実機の可動範囲や制御APIを確認して確定する。

### 顔を発見した場合

- 顔の中心座標を取得する。
- 画像内の顔の位置に応じて首の向きを調整する。
- 顔が画面中央付近に来たら首の動きを止める。
- 鳴き声を1回再生する。
- その後、顔を継続的に追跡する。

### 見つめる動作

- 初期設定では10秒間、相手を見つめる。
- 顔が移動した場合は、首の向きを調整する。
- 顔を見失った場合は短時間再検出を試みる。
- 見つめる時間が終了したら待機状態に戻る。

## 3. State Machine

本機能は、状態機械（Finite State Machine）によって実装する。

```text
WAITING
   |
   | 「MicroDuck！」検知
   v
STANDING_UP
   |
   | 起立完了
   v
SEARCHING
   |
   +-------------------------+
   |                         |
   | 顔を発見                | 顔がない
   v                         v
LOOKING                  ROTATING
   |                         |
   | 首の向き調整            | ランダムに90度旋回
   v                         v
QUACK                    SEARCHING
   |                         |
   | 鳴き声再生              | 顔がない
   v                         v
WATCHING                 WAITING
   |
   | 見つめる時間終了
   v
WAITING
```

### 状態一覧

| State | 役割 |
|---|---|
| `WAITING` | 呼びかけを待つ |
| `STANDING_UP` | 必要に応じて起立する |
| `SEARCHING` | カメラで顔を探索する |
| `ROTATING` | ランダムに選んだ方向へ90度旋回する |
| `LOOKING` | 顔の位置に合わせて首を向ける |
| `QUACK` | 鳴き声を再生する |
| `WATCHING` | 相手を見つめ続ける |

## 4. Technical Architecture

各機能を独立したモジュールとして実装し、`behavior_manager.py` が全体の動作を統括する構成を想定する。

```text
#1_callout/
│
├── README.md
│
├── main.py
│
├── behavior_manager.py
│
├── modules/
│   ├── wake_word.py
│   ├── posture_manager.py
│   ├── face_detector.py
│   ├── search_controller.py
│   ├── head_controller.py
│   └── sound_controller.py
│
└── config/
    └── settings.py
```

### 各モジュールの役割

| Module | Responsibility |
|---|---|
| `main.py` | プログラムの起動 |
| `behavior_manager.py` | 状態遷移・全体管理 |
| `wake_word.py` | 呼びかけの検知 |
| `posture_manager.py` | 姿勢判定・起立 |
| `face_detector.py` | カメラ画像から顔を検出 |
| `search_controller.py` | 旋回方向の決定・探索管理 |
| `head_controller.py` | 顔の位置に合わせた首の制御 |
| `sound_controller.py` | 鳴き声の再生 |
| `settings.py` | 動作パラメータの管理 |

※ファイル構成は暫定案。実装を進めながら変更する。

## 7. Development Roadmap

MicroDuck到着前から、機能ごとに設計・仮実装を進める。

| Step | Task | Goal |
|---|---|---|
| 1 | プロジェクト構成の作成 | Pythonモジュールの役割を理解する |
| 2 | 状態機械の実装 | 行動の流れをプログラムで表現する |
| 3 | 顔検出の検証 | 画像から顔の座標を取得する |
| 4 | 顔の位置計算 | 顔を画面中央に合わせる仕組みを作る |
| 5 | 探索ロジックの実装 | ランダムな90度旋回を設計する |
| 6 | MicroDuck APIの調査 | 実機の機能との接続方法を確認する |
| 7 | 実機テスト | 各動作を個別に検証する |
| 8 | 全体統合 | 呼びかけから応答までを完成させる |

### 開発方針

- MicroDuck到着前は、実機APIが未確認であることを前提に仮コードを書く。
- 実機の制御部分と、一般的なPythonロジックを分離する。
- 実機到着後、公式SDK/APIに合わせて接続部分を実装する。
- まず各機能を単独で動作させ、その後に統合する。
- AIが生成したコードをそのまま採用せず、処理の仕組みを理解してから実装する。

## 8. Safety Considerations

- モーターの直接操作や既存の安全機構の迂回は行わない。
- 起立・旋回・首の制御は、MicroDuckが提供する安全な制御インターフェースを使用する。
- 転倒状態では通常の探索動作を開始しない。
- 動作中に新たな呼びかけを検知しても、既存の行動を重複起動しない。
- 顔検出に失敗した場合は、無限に旋回せず待機状態に戻る。

## 9. Future Extensions

本プロジェクトの基本機能が完成した後、以下の拡張を検討する。

- 自分の顔を登録し、特定の人物だけに反応する（Face Recognition）。
- 音の方向推定（TDOA）を導入し、探索開始方向を最適化する。
- 呼びかけた人の声を学習・識別する。
- 相手との距離や状況に応じて、鳴き声や首の動きを変える。
- 見つけた相手に対して、より自然な感情表現を行う。

これらは現時点では実装対象外。

## 10. Project Goal

最初の完成目標は、次の一連の動作を実機で実現すること。

**「MicroDuck！」と呼ぶと、MicroDuckが起き上がり、顔を探し、見つけた相手の方を向いて鳴き、しばらく見つめる。**

この小さな行動を通して、音声認識・画像認識・状態機械・ロボット制御を組み合わせた、自分自身のロボット開発の第一歩とする。
